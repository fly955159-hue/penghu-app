# 澎湖輪訂票系統 App

依據 [澎湖輪官網](https://tnc-kao.com.tw/) 設計的手機訂票網頁。

## 預覽

雙擊 `index.html` 開啟，或執行：

```bash
npx serve .
```

建議用 Chrome 開發者工具切換手機模式（寬度 390px）預覽。

## 功能

- 首頁訂票卡片（單趟 / 來回、出發地、日期、加購車輛）
- 選擇出發地（高雄 / 澎湖）
- 選擇去程 / 回程日期
- 航班查詢結果（示範）
- 旅客中心、最新消息、側邊選單（連結至官網）

## 檔案

- `index.html` — 頁面結構
- `styles.css` — 官網風格樣式（主色 #163bc0）
- `app.js` — 互動邏輯
